## About

I design and build software end to end: the interface in Figma, the mobile or web client, and the API and database behind it. My current focus is education technology for Bangladesh, with products that serve students, parents and tutors in both Bangla and English.

I work in small, reviewable steps, document decisions as I go, and care about offline-first behavior and clean architecture.

---

## Recent Work

| Project | What it is | Stack |
| --- | --- | --- |
| **TutorLync** | Tutoring platform for Bangladesh with Student, Parent and Tutor roles. Available as a mobile app and a web app, including notifications, classroom join requests, member profiles and an admin verification dashboard. | Flutter, Riverpod, GoRouter, React, TypeScript, FastAPI, MariaDB |
| **Quiz Studio** | Offline-first Windows desktop app for authoring quizzes and flashcards, with local AI support and publishing to Firebase. Designed in Figma. | Tauri 2, React, TypeScript, SQLite, Firebase Realtime Database |
| **Offline Course Player** | Single-page player for downloaded course content, with subtitle conversion, progress tracking, per-lesson study time and a study history dashboard. | JavaScript, HTML5, localStorage |
| **Portfolio** | Personal site showing every skill alongside the project that proves it, with an admin app planned to manage its content. | HTML, CSS, JavaScript, Firebase, React |
